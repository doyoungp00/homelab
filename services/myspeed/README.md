# What it's for

MySpeed runs internet speed tests on a schedule and keeps a history of the results.

[Check out the project](https://github.com/gnmyt/myspeed)

# Why it's needed

It shows whether the ISP is delivering the speed being paid for, and helps tell a slow connection apart from a problem inside the network. Note that this tool is just a way to keep a pulse on the internet connectivity. ISPs will **not** accept a claim if the test wasn't performed by their specified testing tool in their specified environment.

# Known caveats

1. Each test uses the full bandwidth for a short while, which can affect anything else running at the same time. Don't schedule tests too often.
